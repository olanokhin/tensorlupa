---
title: "Словарик терминов"
description: "Все термины студии в одной таблице: перевод, объяснение в одну фразу и ссылка на статью."
---

В подписях студии термины стоят так, как вы встретите их в статьях, коде и документации, чаще всего по-английски. Здесь у каждого есть перевод и объяснение в одну фразу. То же самое видно в студии, если навести на подчёркнутый термин.

| Термин | По-русски | В подписях студии | В одну фразу |
| --- | --- | --- | --- |
| **language model** | языковая модель | языковая модель | Предсказывает следующий кусочек текста: читает написанное, оценивает каждый возможный следующий токен, выбирает один, дописывает его и повторяет. [статья](../glossary/language-model/) |
| **token** | токен | токен | Кусочек текста, который модель читает и пишет: целое слово, часть слова или знак. micro-qwen3 знает 4096 токенов. [статья](../glossary/token/) |
| **prompt** | промпт | промпт | Всё, что модель читает до ответа. Здесь это ваша просьба в служебных метках чата. Ответ (completion) модель пишет после него. [статья](../glossary/prompt/) |
| **special token** | служебный токен | служебный токен | Зарезервированная метка, а не текст. `<\|im_start\|>` и `<\|im_end\|>` открывают и закрывают реплику в чате, `<\|endoftext\|>` завершает текст. Историю модель заканчивает сама, когда пишет `<\|im_end\|>`. [статья](../glossary/special-tokens/) |
| **Instruct** | по инструкции | Instruct | Модель выполняет просьбу, записанную в формате чата. Здесь это история с вашими словами. [статья](../glossary/instruct/) |
| **Completion** | продолжение текста | Completion | Модель просто продолжает начатый вами текст, без всякой просьбы. [статья](../glossary/completion/) |
| **transformer** | трансформер | трансформер | Каждый токен превращается в список чисел, проходит три слоя attention и MLP и на выходе даёт оценку каждому следующему токену. [статья](../glossary/transformer/) |
| **embedding** | эмбеддинг | эмбеддинг | Превращает токен в список из 112 чисел. С него начинается путь токена через слои. [статья](../glossary/residual-stream/) |
| **residual stream** | остаточный поток | остаточный поток | Текущий список чисел токена. Каждый слой читает его и добавляет сверху свой вклад. [статья](../glossary/residual-stream/) |
| **attention** | внимание | attention | Позволяет каждому токену оглянуться на прежние и взять из них то, что нужно для предсказания следующего. [статья](../glossary/attention/) |
| **attention head** | голова | голова attention | Один независимый способ оглядываться назад. В каждом слое четыре головы, и каждая учится замечать своё. [статья](../glossary/attention-head/) |
| **attention weights** | веса | веса attention | Какую долю внимания голова отдаёт каждому прошлому токену. [статья](../glossary/attention-head/) |
| **value-weighted** | с учётом value | с учётом value | Вес × сколько информации голова реально забирает из токена. Смотреть и брать не одно и то же. [статья](../glossary/attention-head/) |
| **KV cache** | кэш ключей и значений | KV-кэш | Хранит ключ и значение каждого прошлого токена, чтобы считать их один раз, а не на каждом шаге. [статья](../glossary/grouped-query-attention/) |
| **GQA** | attention с общими ключами | GQA | Несколько голов задают свои запросы, но читают один набор ключей и значений, поэтому KV-кэш меньше. [статья](../glossary/grouped-query-attention/) |
| **QK-norm** | нормировка запросов и ключей | QK-norm | Приводит запросы и ключи к одному масштабу перед сравнением, чтобы оценки attention держались в ровном диапазоне. [статья](../glossary/qk-norm/) |
| **RoPE** | поворотное кодирование позиции | RoPE | Сообщает attention порядок слов: запросы и ключи поворачиваются на угол, зависящий от позиции. [статья](../glossary/rope/) |
| **RMSNorm** | нормировка по среднеквадратичному | RMSNorm | Приводит поток к одному масштабу, прежде чем его прочитает блок, чтобы блок видел его одинаково на любой глубине. [статья](../glossary/rmsnorm/) |
| **MLP** | многослойный перцептрон | MLP | Вторая половина каждого слоя. 336 нейронов на слой реагируют на шаблоны и подталкивают одни следующие слова вверх, другие вниз. [статья](../glossary/mlp/) |
| **SwiGLU** | MLP с затвором | SwiGLU | Устройство MLP: вход разворачивается дважды, как сигнал и как затвор, и затвор решает, сколько каждого сигнала пройдёт. [статья](../glossary/swiglu/) |
| **logit lens** | линза логитов | logit lens | Прочитать поток в середине модели так, будто это её конец, и увидеть, что она сказала бы на этом месте. [статья](../glossary/logit-lens/) |
| **logits** | логиты | логиты | Сырые оценки модели для всех 4096 токенов. Softmax превращает их в вероятности, которые в сумме дают 100%. [статья](../glossary/logits/) |
| **sampling** | сэмплинг | сэмплинг | Как из вероятностей выбирается один токен. Это взвешенный жребий, которому форму задают температура и top-k. [статья](../glossary/sampling/) |
| **temperature** | температура | температура | Насколько смелый выбор. Низкая почти всегда берёт самый вероятный токен, высокая даёт неожиданные слова и больше ошибок. [статья](../glossary/temperature/) |
| **top-k** | K лучших | top-k | Модель выбирает только среди K самых вероятных токенов, остальные исключены. [статья](../glossary/top-k/) |
| **min-p** | порог от фаворита | min-p | Модель не выбирает токен, который в 1/min-p раз и более менее вероятен, чем фаворит. При 0,02 отсекаются токены, в 50 раз менее вероятные: редкие срывы, которые ломают слова. [статья](../glossary/min-p/) |
| **seed** | зерно случайности | seed | Число, которое задаёт случайные броски. Тот же seed и те же настройки дают ровно ту же историю. [статья](../glossary/seed/) |
| **entropy** | энтропия | энтропия | Насколько размазан выбор, в битах: 0 значит полностью уверена, больше значит спорят больше вариантов. [статья](../glossary/entropy/) |
| **max new tokens** | макс. новых токенов | макс. новых токенов | Самый длинный ответ, который модель может написать, в токенах. [статья](../glossary/max-new-tokens/) |
| **repetition penalty** | штраф за повторы | штраф за повторы | Понижает оценку токена, который повторил бы фразу из четырёх токенов, уже написанную в этой истории, если только эта фраза не частая в детских историях («Once upon a time»). Опирается на статистику обучающего корпуса. [статья](../glossary/repetition-penalty/) |
| **logit bias** | доплата к оценке | logit bias | Доплата к оценке токена перед выбором, здесь для ещё не использованных ключевых слов. [статья](../glossary/logit-bias/) |
| **constrained decoding (FSM)** | декодирование с ограничениями | constrained decoding (FSM) | Когда ключевое слово начато, маленький конечный автомат (FSM) заставляет модель дописать его по буквам. [статья](../glossary/fsm/) |
