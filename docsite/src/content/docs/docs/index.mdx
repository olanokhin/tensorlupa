TensorLupa runs a real language model, micro-qwen3, in your browser and shows every step of its work. These pages
explain each thing you see in the studio: what it is, where to find it, and a link that opens the studio at the
exact moment where it is easiest to see.

Every number here comes from the model itself, not from an illustration.

## Basics

Start here if you are new to language models. The pages follow the order in which things make sense:

1. [Language model](glossary/language-model/): what the model actually does, one token at a time.
2. [Token](glossary/token/): the pieces of text the model reads and writes.
3. [Prompt](glossary/prompt/): what the model reads before it answers.
4. [Special tokens](glossary/special-tokens/): the hidden chat markers, and how the model decides to stop.
5. [Completion](glossary/completion/): continuing text, the mode every model starts with.
6. [Instruct](glossary/instruct/): how a model learns to follow a request.
7. [Transformer](glossary/transformer/): what happens inside at every step.
8. [Embedding and residual stream](glossary/residual-stream/): the numbers a token turns into.
9. [Attention](glossary/attention/): how a token looks back at earlier ones.
10. [MLP and neurons](glossary/mlp/): the neurons in every layer.
11. [Logits](glossary/logits/): scores for every possible next token.
12. [Sampling](glossary/sampling/): how one token is chosen.
